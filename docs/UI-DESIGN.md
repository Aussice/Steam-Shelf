# Steam Shelf 0.7 界面

参照 Steam 游戏库的桌面客户端语言，独立实现，不使用或宣称 Valve 官方前端组件。

- 顶部：Steam Shelf、游戏库入口、帮助与游戏库管理。
- 左侧：全部游戏、我的收藏、安装状态及游戏分类，桌面默认展开。
- 中间：真实游戏数量与搜索筛选；3D 书架填满窗口剩余空间。
- 下方：居中翻页和本地收藏状态，保持导航位置稳定。
- 抽盒、360° 查看、布置及导入面板共用颜色、字号和按钮规则。

| 用途 | 颜色 |
| --- | --- |
| 顶栏与底栏 | `#171a21` |
| 侧栏 | `#20242d` |
| 工作区 | `#252b36` |
| 主要文字 | `#dfe3e8` |
| 次要文字 | `#a6b1c1` |
| 选中提示与焦点 | `#66c0f4` / `#1a9fff` |
| 主按钮 | `#1b6fae` 至 `#1a619f` |
| 启动游戏 | `#507716` |

常规界面文字 12 至 14px，页面标题 26px，按钮采用 2px 圆角。
保留键盘焦点、Ctrl K 搜索、空状态、封面错误、3D 不可用提示、减少动态效果和小屏布局。
手柄使用原有现成 PS5 DualSense，缩小为 0.6 版的一半，正面旋转至 +Y，按钮朝上；按模型真实包围盒让背壳落在层板上。三种饰面奖杯缩小 25%，并按相同比例收紧间距。手柄和三种饰面奖杯均可单击进入独立 360° 查看，也可从「摆件」菜单进入。首次升级默认胡桃木，之后记住手动选择；底部控制条统一 13px 字号、36px 按钮高度。
